## About

I'm an **AWS Community Builder** and software engineering student focused on building AI-powered and cloud-native systems — and talking about them publicly.

During my internship at **Mirai Innovation Research Institute (Osaka, Japan)**, I engineered a real-time 3-device synchronization system connecting EEG signals to a VR adaptive experience over a local WiFi network — without proprietary hardware. That experience shaped how I think about building under real constraints.

Outside of building, I'm a **technical speaker** at AWS and JavaScript community events across Latin America, and the founder of **AWSpectrum**, a tech event focused on AWS and LGBTQ+ visibility in tech.

## 🔬 Featured Projects

### [NeuroCopilot](https://github.com/Shel-y/Neurocopilot) — AI Copilot for EEG Analysis
Multi-agent AI system using LangChain/LangGraph and local LLMs to analyze simulated EEG signals. Includes quantum-inspired feature mapping, anomaly detection, and a Gradio interface for real-time visualization.
`Python` `LangChain` `LangGraph` `Gradio` `Ollama`

---

### [Sorority](https://github.com/Shel-y/Sorority) — 3D Decentralized Trust Network
High-performance bridge between Rust and Flutter to visualize a real-time safety alert propagation network. Rust handles simulation logic; Flutter renders a live 3D sphere using Dart FFI with near-zero latency.
`Rust` `Flutter` `Dart FFI` `FFI Bridge`

---

### [Quantum-Inspired Cloud Optimization](https://github.com/Shel-y/quantum-inspired-cloud-optimization) — AWS + Quantum PoC
Reference architecture for hybrid classical-quantum pipelines using AWS Braket, S3, EC2, and CloudWatch. Built for my talk at AWSome Women Summit LATAM 2026.
`Python` `AWS Braket` `Boto3` `CloudWatch`

---

### [Quantum Computing Foundations](https://github.com/Shel-y/Quantum-Computing-Foundations) — Mathematical Simulations
Interactive Jupyter notebooks simulating qubit representation, quantum gate transformations, and unitary rotations using NumPy and Matplotlib. Built for scientific outreach and personal depth.
`Python` `NumPy` `Matplotlib` `Jupyter`
